Your words. Your folders.

Choose a folder and describe a task, like “sort by file type” or “group by month.” Tidy turns your request into a validated plan.

02

On your Mac.

File processing and AI inference run locally. No account, cloud inference, or app telemetry. Initial model setup needs a separate download of about 2.28 GB.

03

A way back.

History keeps track of changes, with best-effort undo. Clear requests change files without a preview, so always keep a backup.

A work in progress. Built for Apple silicon and targeting macOS 14 or later; hardware requirements are not yet qualified. Existing sync services can still transmit changes in synced folders.
