# Tidy landing page

Static GitHub Pages site for Tidy, maintained on the `gh-pages` branch. GitHub Pages
publishes the root of this branch. No build tools, JavaScript, analytics, or external
fonts are required.

Preview with `python3 -m http.server 8080` and open `http://localhost:8080`.

The icon reuses the approved `Packaging/Icons/Tidy.png` from the app's development
branch. The Releases link deliberately points to the release list, not
`releases/latest`, because no public app release exists yet. When a qualified release
is published, update the availability copy and hardware requirements, and link to
the latest release. Publishing this site does not publish or qualify an app build.
