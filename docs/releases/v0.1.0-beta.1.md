## Honest availability and limits

This beta is for voluntary testing with disposable, backed-up files. No Mac
configuration is formally qualified. Builds target Apple silicon and macOS 14+;
the model setup's 16 GB floor is provisional, not verified hardware support.
Observed development runs used an M4 Max with 36 GB RAM and macOS 27.0.1.

Native grants/revocation and real-provider nonhydration, independent real-world
naming assessment, other hardware/macOS versions, memory pressure/native parser
peaks, actual process/power-loss stress and isolated destructive lifecycle controls
remain unverified beyond their recorded tests. Synthetic/agent scores do not
establish independent quality or a safety guarantee. Clear requests execute without
preview. Undo is best-effort, not a backup. Avoid personal or synced folders while
testing; existing sync services can transmit changes.

The approximately 2.28 GB model is downloaded separately with consent. There is
no account/payment, cloud inference or automatic telemetry. Project MIT terms
do not replace bundled dependency/model licenses or establish naming clearance.
